# Suivi des projets électriques MT / BT

Application web de suivi des projets électriques avec :

- gestion des projets MT et BT ;
- ajout, modification et suppression ;
- recherche et filtres ;
- budgets prévus, engagés et dépensés ;
- phases SIA ;
- diagrammes de Gantt par projet ou pour l'ensemble des projets ;
- gestion de plusieurs responsables ;
- impression et export JSON ;
- sauvegarde locale dans le navigateur.

## Publication

Le site est prévu pour GitHub Pages depuis la branche `main` et le dossier racine `/root`.

> Cette version est une application statique. Les utilisateurs représentent des responsables de projets, mais il n'y a pas encore d'authentification ni de base de données partagée entre plusieurs appareils.
